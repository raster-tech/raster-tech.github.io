Error codes

What a code means, and what to do about it.

When Tech Sheet or Label Station can't do something, it tells you in one sentence, gives you one thing to try, and ends with a short code in brackets, like (TS-SHEET-001).

Find your code below and try the fix. If that doesn't sort it out, email support@rastertech.app with:

  1. The code, exactly as shown.
  2. What you were doing when it appeared, in a line.
  3. Your error log, if you can:
  • Tech Sheet: Settings → Error log → Export. Or tick "include my recent log" when you use Send feedback.
  • Label Station: Settings → Error log → Export, and attach the file. Or Copy it and paste it into your email.

The log never includes your sign-in or keys. Nothing is sent unless you send it.

If your show can't run, put SHOW DOWN in the subject line.

Reading a code: TS is Tech Sheet and LS is Label Station. The middle word says where the problem is: AUTH is Google sign-in, SHEET is your show sheet, AUDIT is checking devices, NET is network setup, NEWSHOW is creating a show, RENDER is laying out a label, PRINT is the printer, UPDATE is Check for Updates, and APP is the app itself. A code always means the same thing, and is never reused.

Tech Sheet

Sign-in (TS-AUTH)

CodeWhat happenedTry this
TS-AUTH-001Google sign-in didn't work, for a reason Google didn't explain.Check the internet connection and try again. If it keeps failing, send the error log.
TS-AUTH-002Your saved Google sign-in stopped working.Sign in again.
TS-AUTH-003The Google sign-in or file-picker window wasn't finished in time.Try again, and finish in the browser window that opens.
TS-AUTH-004Google's reply belonged to a different sign-in, often an older tab.Close any other sign-in tabs, then try again.
TS-AUTH-005Google ended the sign-in before it finished, usually because Cancel was pressed.Try again and choose Allow, using the account the sheet is shared with.
TS-AUTH-006Pick Your Sheet was used from a phone or another computer.Pick the sheet on the computer running Tech Sheet.
TS-AUTH-007Pick Your Sheet was used on a computer set up with a service account.Paste the sheet link in Settings → Switch Show instead.
TS-AUTH-008This copy of Tech Sheet is missing a file it needs to sign in.Reinstall Tech Sheet.

Your show sheet (TS-SHEET)

CodeWhat happenedTry this
TS-SHEET-001Tech Sheet couldn't read your show sheet, and has no earlier copy to show.Check the internet connection, and open the sheet in a browser to check it's still shared with you. Tech Sheet keeps retrying.
TS-SHEET-002A read failed, so the dashboard is showing the last good copy.Usually nothing: it clears on the next good read. If it lasts many minutes, check the internet connection.
TS-SHEET-003The sheet is missing a tab Tech Sheet needs (START HERE or GEAR INDEX).Check it wasn't renamed or deleted, or pick the show's own Tech Sheet.
TS-SHEET-004Tech Sheet couldn't even read the sheet's list of tabs.Open the link in a browser as the same Google account, then share it again or pick it again.
TS-SHEET-005GEAR INDEX is missing a column Tech Sheet reads (Device ID or Equipment Type).Check the headers in row 1 weren't renamed or deleted. Compare with a fresh template copy.
TS-SHEET-006The SHOW ID on START HERE is empty. Every address comes from it.Type the show's number in START HERE, cell A16 (the yellow cell).
TS-SHEET-007A Subnet Size on IP INDEX isn't a size Tech Sheet understands.Use /8, /16 or /24, or leave it blank for /24.
TS-SHEET-008Connecting to that sheet failed.Open the link in a browser as the same account, check it's a Tech Sheet copy, then try again.
TS-SHEET-009 (0.1.16)The SUB PACKET tab doesn't have room to save the section order.Add as many empty rows under SECTIONS as the message says, then build again.

Checking devices (TS-AUDIT)

CodeWhat happenedTry this
TS-AUDIT-001An audit stopped partway on an unexpected problem.Run the audit again. If it happens again, send the error log.
TS-AUDIT-002This computer isn't on the show network. (Wi-Fi can't reach it.)Connect it to the show switch with a cable, then press Audit Now. If it still can't see the show, use Settings → This Computer → Set up this computer's network.
TS-AUDIT-003The audit took too long, so it was stopped.Check this computer is on the show network, then press Audit Now again.

Network setup (TS-NET)

CodeWhat happenedTry this
TS-NET-001This edition of Windows (Home) can't run network setup.Use a computer with Windows Pro, Enterprise or Education, or a Mac.
TS-NET-002Hyper-V is off. Network setup uses it to add the VLAN adapters.Click Turn on Hyper-V. It takes about a minute and one restart; you can look at the plan first.
TS-NET-003Hyper-V was just turned on and needs a restart.Restart, then open network setup again. Your choices are kept.
TS-NET-004Hyper-V is on, but may not be running.If Run fails, turn on virtualization (called Intel VT-x or AMD-V / SVM) in this computer's BIOS/UEFI settings, then restart.
TS-NET-006The administrator prompt was canceled, so nothing was changed.Run again and click Yes on the prompt (on a Mac, enter the password).
TS-NET-007This step needs administrator rights, so nothing was changed.Sign in with an administrator account, or ask whoever manages this computer (on a work laptop, often IT).
TS-NET-008Setup stopped before changing anything: its working folder doesn't look right.Don't delete anything yet. Copy the error log (Settings → Error log → Copy) and email it to us.
TS-NET-009Setup couldn't read the network card's own settings, so it left the card alone.Check the card is plugged in (and the adapter, if it's USB), reopen network setup, and try again.
TS-NET-010The network card you picked isn't there anymore.Reconnect it, reopen network setup, and pick it again.
TS-NET-011(Mac) The card has no network service of its own yet.Add one in System Settings → Network → ⋯ → Add Service, choose your Ethernet adapter, then run setup again.
TS-NET-014(Mac) A VLAN is named like setup's, but its tag is a different number, so setup won't touch or remove it.Rename it or fix its tag in System Settings → Network → ⋯ → Manage Virtual Interfaces.
TS-NET-015Network setup hit a problem it doesn't have a message for yet.Copy the error log (Settings → Error log → Copy) and email it to us.
TS-NET-016Setup couldn't read this computer's network settings from Windows.Close and reopen network setup. If it happens again, send the error log.
TS-NET-017Too many VLANs were ticked for one step.Tick fewer, run setup, then run it again for the rest (choose Skip for the ones already made).
TS-NET-018 (0.1.16)Network setup hasn't changed anything on this computer, so there's nothing to remove.Nothing to do. This only means there's nothing to undo.
TS-NET-019 (0.1.16)The Dashboard reachable on setting couldn't switch to that network, because its network settings couldn't be changed.Try again, and click Yes (or enter your password) if asked. If it keeps failing, send the error log.

Updates (TS-UPDATE)

CodeWhat happenedTry this
TS-UPDATE-001Check for Updates couldn't reach the download page.Check the internet connection and try again later. Your current version keeps working.
TS-UPDATE-002The update download didn't finish.Try again on a steadier connection, or download the installer from the release page.
TS-UPDATE-003The update couldn't be saved to your Downloads folder.Free some disk space, or check the Downloads folder isn't read-only, then try again.
TS-UPDATE-004GitHub is limiting update checks from this network, which is common on shared venue internet.Try again in about an hour. Your current version keeps working.
TS-UPDATE-005GitHub's answer about updates wasn't one Tech Sheet could use.Try again later. If it keeps happening, send the error log.
TS-UPDATE-006 (0.1.16)The update didn't download cleanly, so Tech Sheet deleted it. Nothing was installed, and this version keeps working.Try Check for Updates again. If it happens twice, download the installer from the release page instead.

Licenses (TS-LICENSE)

*These only appear once paid plans start. During the beta, Tech Sheet is free and never asks for a license. Without a license, the core audit (Audit Now, results, live status, New Show) always keeps working; only the paused features below say so.*

CodeWhat happenedTry this
TS-LICENSE-001This computer has no license, so a licensed feature (the Sub Packet, remote screens or network setup) is paused.Activate a license in Settings → This Computer → License.
TS-LICENSE-002This computer's license has ended, so a licensed feature is paused. Nothing was lost.Renew in Settings → This Computer → License.
TS-LICENSE-003This computer's plan doesn't include that feature. Everything else keeps working.See which plans do at license.rastertech.app/account.
TS-LICENSE-004The version your license is for doesn't cover that feature.Upgrade in Settings → This Computer → License.

The app (TS-APP)

CodeWhat happenedTry this
TS-APP-001The dashboard lost touch with Tech Sheet.Check Tech Sheet is still running (tray or menu bar), then refresh. On a phone, check you're on the show network.
TS-APP-002The error log's folder wouldn't open.Use Copy or Export in Settings → Error log instead.
TS-APP-003Tech Sheet couldn't start, because other programs are using its connection (its whole range of ports).Quit the other program, or restart this computer, then start Tech Sheet again. From 0.1.16 this is rare: Tech Sheet moves to the next free port by itself, including when AirPlay holds 5000.
TS-APP-004The Sub Packet couldn't be built.Try again, and check there's free disk space. If it happens again, send the error log.
TS-APP-005The dashboard is locked, so the change was refused.Unlock it with the PIN, then try again.
TS-APP-006This copy was started without an error log.Run the installed Tech Sheet.
TS-APP-007The error log was opened from a phone or another computer.Open it on the computer running Tech Sheet.
TS-APP-008This copy doesn't keep its error log in a folder.Use Copy or Export instead.
TS-APP-009Something went wrong that Tech Sheet doesn't have a message for yet.Try again. If it happens again, send the error log.
TS-APP-010Tech Sheet is already running on this computer, so a second copy didn't start. From 0.1.16 this includes a copy another person has open in their own session on the same computer.Use the copy in the tray or menu bar. If it's someone else's session, use theirs, or have them quit it first.
TS-APP-011Tech Sheet didn't finish starting.Start it again. If this keeps happening, check security software isn't blocking it.
TS-APP-012A Sub Packet build was started from a phone or another computer.Build it on the computer running Tech Sheet, or open the last one from Settings.
TS-APP-013Remote screens were switched from a phone or another computer.Switch them on the computer running Tech Sheet.
TS-APP-014Remote screens are off for this show.Turn them on in Settings, on the computer running Tech Sheet.
TS-APP-015That device isn't set up for REMOTE in the show sheet.Check its row in GEAR INDEX, then refresh.
TS-APP-016 (0.1.16)The port typed in the tray panel's Port field is one browsers refuse to open.Pick a different port, like 5001.
TS-APP-017 (0.1.16)Tech Sheet couldn't change the Windows Firewall, so phones still can't connect.Try again. If it keeps failing, send the error log from Settings → Error log.
TS-APP-018 (0.1.16)A phone, tablet or another computer tried a change only the computer running Tech Sheet can make: switching the show, signing out, replacing the sign-in, setting or changing the PIN, or pausing live monitoring.Make the change on the computer running Tech Sheet. Viewing the dashboard works from any device.
TS-APP-019 (0.1.16)This dashboard is set so phones and tablets need its PIN even to view it.Enter the PIN on the phone's PIN screen, or ask the person running Tech Sheet. It can be turned off on that computer in Settings → Dashboard Lock.
TS-APP-020 (0.1.16)Tech Sheet couldn't turn Run at Login on or off.Try again. If it keeps failing, send the error log from Settings → Error log.

CodeWhat happenedTry this
LS-SHEET-001Label Station couldn't reach Google Sheets. Rows already read stay on screen.Check the connection, then press Refresh.
LS-SHEET-002Google Sheets didn't answer.Press Refresh to try again.
LS-SHEET-003The sheet was made from an older template and doesn't have this tab.Add the tab from the current template to use it. The other tabs still work.

LS-SHEET-005No show sheet is connected yet.Press Pick Your Sheet.
LS-SHEET-006The sheet isn't set up as a show sheet yet (a missing tab, SHOW ID, column or subnet size).Check START HERE and GEAR INDEX against the template, then press Refresh.
LS-SHEET-007A FLOW row names a device that isn't in GEAR INDEX, usually a typo or a renamed device.Change it to the device's GEAR INDEX name.
LS-SHEET-008The sheet has no SHOW ID yet, as on a fresh copy of the template.Fill in the yellow SHOW ID cell on START HERE, then press Pick Your Sheet (or Refresh) again.
LS-SHEET-009 (next LS update)A FLOW row has no Cable #, and this show is set not to print cables without one.Give it a Cable # on the FLOW tab, then press Refresh.

LS-RENDER-003A length or size is outside what this label allows.Check that length or size in the sheet or the preset.

LS-RENDER-006That preset was made for a different label.Import it on the tab it was made for.
