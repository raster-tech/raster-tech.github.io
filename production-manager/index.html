Production Manager

Production Manager is one place to see every show you're tracking — how each one last checked in, what's coming up, and what needs attention before you get there. It's a desktop app you install on your own computer, the same way as Tech Sheet — nothing hosted by Raster. It connects, read-only, to each show's Tech Sheet — one small utility computer per show — over your own private network.

Coming around mid-November.

Want to know when it's ready for other engineers to try? Email support@rastertech.app and we'll let you know — no signup, no list, just a note when it's ready.
