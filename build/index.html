Raster Build

Makes your show’s tech sheet, from the first rider to the last LED wall.

Raster Build is where a show's tech sheet gets made. Start a new show, or import the gear straight from the rider or bid PDF. Then fill in the gear and IP index, the LED walls and the full canvas, and the pull lists, all in one window at your desk or in the shop.

What it does:

  • Start a new show from the starter template, in your own Google Drive.
  • Import from a rider: pick the PDF and the section, check the gear list, then create the sheet. Video, Audio and Lighting.
  • The gear and IP index: names, addresses, sections and VLANs, from the same rules every time.
  • LED walls and the full canvas: each wall's processors, outputs and place on the canvas.
  • Pull lists, and the handoff to Raster Label for the labels.
  • Show health from afar: see how a running show is doing, as reported by Raster Run on the show computer.

The tech sheet stays the source of truth: Build writes it, Raster Label prints from it, and Raster Run keeps the show running against it.

In development. Raster Build joins Raster Run and Raster Label as a public beta.
