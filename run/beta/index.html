Join the beta

Download it, pick your show, and start your first audit.

Raster Run is a new tool, tested on real shows. It’s free while it’s in beta. Expect rough edges, and tell us what breaks.

What you need: a Windows 10 or 11 (64-bit) laptop that can plug into your show network, and a Google account that can open your show’s tech sheet.

Get started

  1. Downloadthe latest build from the release page.
  2. Install it. The installer isn’t code-signed yet, so the first time Windows says "Windows protected your PC": click More info → Run anyway. The warning is about the missing signature, not anything found in the app.
  3. Pick your show and run an audit. Sign in and pick your show’s tech sheet (no sheet yet? make one in Raster Build). Then plug into the show network and press Audit Now.
Download for Windows

The full walkthrough, step by step, is in the beta guide — it ships attached to each release.
